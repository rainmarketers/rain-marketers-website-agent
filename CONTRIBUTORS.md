## How This Project Started

The Website Post-Onboarding Agent was built to streamline how Rain Marketers helps small business clients transition from initial onboarding to website strategy development.

**Problem**: Clients needed strategic guidance on positioning, messaging, and site structure, but manual analysis was time-intensive.

**Solution**: Created an AI-powered agent that:
- Analyzes current client positioning
- Researches 5-7 direct competitors
- Identifies defensible positioning gaps
- Generates strategic briefs and content templates
- Creates Asana tasks for handoff to design/dev teams

## How to Contribute

### Found a Bug?

1. Open an issue with:
   - What you expected
   - What actually happened
   - Steps to reproduce

2. Include:
   - Client name/industry (if shareable)
   - Website URL analyzed
   - Agent output section that had the issue

### Have an Idea?

1. Check [ARCHITECTURE.md](docs/ARCHITECTURE.md) for future skill possibilities
2. Open an issue describing:
   - What problem it solves
   - How it fits into the system
   - What reference docs it would need

### Want to Add a Skill?

The system is designed for extension:

1. Read [ARCHITECTURE.md](docs/ARCHITECTURE.md) → "Adding a New Skill" section
2. Create `skills/your-new-skill/` directory
3. Write SKILL.md and reference docs
4. Update main README
5. Submit a pull request

**Example new skills** (ideas, not committed):
- Website copywriting agent
- Design system generator
- SEO optimization recommendations
- Performance audit agent

### Found an Improvement?

For any of these:
- Better examples
- Clearer documentation
- Improved templates
- New reference materials

Open a PR with your changes.
