# Rain Marketers

A structured repository for AI skills and agents.

## 📁 Structure

```
rain-marketing-website-agent/
├── skills/                    # AI skills live here
│   └── [skill-name]/
│       ├── SKILL.md          # Skill definition
│       └── references/        # Supporting docs (optional)
│
├── agents/                    # Subagents live here
│
├── docs/
│   ├── SETUP.md
│   ├── USAGE.md
│   └── ARCHITECTURE.md
│
└── README.md (this file)
```

## 🚀 Adding a Skill

Create a new folder under `skills/` with your skill name:

```bash
mkdir skills/[your-skill-name]
```

Add a `SKILL.md` file with:
- What it does
- Input/output format
- Execution stages
- Success criteria
