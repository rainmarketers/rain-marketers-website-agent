# Website Copywriting Agent

**Create all website copy aligned with positioning and messaging**

Produces benefit-focused, conversion-optimized copy for every page of the website, following positioning pillars and target audience psychology.

---

## What It Does

Executes Phase 2.1 of service fulfillment: Transforms website brief strategy into actual copy for all pages, CTAs, and conversion elements.

**Input**: Website brief + positioning + messaging pillars + target audience

**Output**: Complete website copy for all recommended pages, CTA variants, copy hierarchy

---

## Execution

### Stage 1: Homepage Copy (2 days)
- **Hero section** (headline + subheadline + CTA)
- **Value propositions** (3-4 benefit blocks matching messaging pillars)
- **Social proof section** (testimonials framework, results, trust signals)
- **Final CTA section** (risk-reversal messaging)

**Approach**: Problem → Solution → Trust → Action

### Stage 2: Services/Offerings Pages (1 day)
- **Service detail pages** (what's included, benefits, pricing)
- **Service comparison** (if multiple offerings)
- **Process/How It Works** (4-5 step process visualized)
- **Pricing page** (transparent, benefit-focused)

**Approach**: Feature → Benefit → Proof → CTA

### Stage 3: Trust/Credibility Pages (1 day)
- **About Us / Our Story** (founder story, mission, values)
- **Why Choose Us** (differentiators + competitive advantages)
- **Customer testimonials** (emotional + results-focused)
- **Before/After or Case Studies** (visual proof framework)

**Approach**: Social proof → Expertise → Confidence building

### Stage 4: Addressing Objections (0.5 days)
- **FAQ section** (common questions + confident answers)
- **Service Area coverage** (if location-based)
- **Contact/Booking CTA** (multiple options)

**Approach**: Overcome resistance → Make action easy

## Copy Principles

✍️ **Benefit-focused, not feature-heavy**
- "Never climb a ladder again" vs "15-foot aluminum extension ladder"
- Focus on outcome the customer wants, not what you do

✍️ **Audience-specific language**
- Match target psychographics (professional, careful, busy, etc.)
- Use language that resonates (trust, speed, peace of mind, etc.)

✍️ **Proof-driven claims**
- Every big claim backed by proof point
- "20+ years experience" → proof point
- "Same-day service" → proof point (95% within 24 hours)

✍️ **Clear CTAs**
- Action-oriented verbs (Schedule, Book, Get, Claim)
- Create urgency without pressure (Limited spots, Free offer)
- Multiple CTAs at different stages of page

✍️ **Scannable structure**
- Short paragraphs (2-3 sentences max)
- Clear subheadings
- Bullet points for benefits
- Visual breaks
